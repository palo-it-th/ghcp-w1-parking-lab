# Lab 1.1 · คลินิก prompt (10 นาที)

**เรื่องที่ฝึก:** Context + Goal + Constraint
ถ้าไม่บอกว่าดูอะไร จะเช็กยังไงว่าสำเร็จ และห้ามแตะอะไร agent จะเดาเอง วนค้นหลายรอบ แล้ว diff จะลามไปไฟล์ที่ไม่เกี่ยว

## สถานการณ์

ฝ่ายบริหารห้างบอกว่ารายงานเมื่อเช้ามี "เวลาจอดเฉลี่ย" เป็น `NaN` และมีคนในทีมส่ง prompt สามอันนี้มาให้ Copilot
ทั้งสามอันมีปัญหา

| # | Prompt ที่ไม่ดี |
|---|---|
| A | `รายงานมันแปลกๆ ช่วยแก้หน่อย` |
| B | `ใบเสร็จอ่านยาก ทำให้มันดีขึ้น` |
| C | `เขียน test เพิ่มให้ครบ` |

## ทำ

1. New Chat → Agent แล้วส่ง **prompt A ตามที่เขียนไว้ทุกตัวอักษร**
2. ดู diff ว่าแตะไฟล์ไหนบ้าง แล้วกางรายการ tool call ใต้คำตอบออก นับว่า agent อ่านไฟล์ ค้นหา และรันคำสั่งไปกี่ครั้ง
   จดทั้งสองอย่างลงใน worksheet จากนั้นกด **Undo** ทั้งหมด
3. เขียน prompt A ใหม่ให้มีครบสามส่วน:
   - **Context:** ไฟล์ไหน (ใช้ `#file`) และอาการเป็นยังไง
   - **Goal:** ต้องได้ผลอะไร และเช็กยังไงว่าสำเร็จ
   - **Constraint:** อะไรห้ามเปลี่ยน
4. New Chat แล้วส่ง prompt ใหม่ เทียบ diff และจำนวน tool call กับรอบแรก
5. ถ้ามีเวลาเหลือ ทำแบบเดียวกันกับ B หรือ C

> ใบ้: ลองเพิ่มบัตรหายเข้าไปในรายการ exit ของ `dailySummary()` ดู

## เสร็จเมื่อ

prompt ที่เขียนใหม่ทำให้ diff แตะแค่ไฟล์ที่ควรแตะ test ทั้งหมดยังเขียว และคุณบอกได้ว่าทำไมรอบนี้ agent เรียก tool น้อยกว่ารอบแรก

## ใช้โค้ดของตัวเอง

นึกถึง prompt สั้นๆ ที่คุณเคยพิมพ์แล้วได้ผลไม่ตรงใจ ลองรันอีกครั้ง แล้วเขียนใหม่ให้มีครบสามส่วน
