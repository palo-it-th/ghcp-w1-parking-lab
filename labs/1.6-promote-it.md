# Lab 1.6 · Promote it (4 นาที)

**เรื่องที่ฝึก:** prompt ที่พิมพ์ซ้ำ ให้บันทึกเป็นไฟล์ แล้วชื่อไฟล์จะกลายเป็น `/command`

## สถานการณ์

ใน Lab 1.3 คุณได้ prompt สำหรับเขียน test ที่ดีที่สุดมาแล้ว และทีมยังต้องเขียน test แบบนี้ให้อีกหลาย function

## ทำ

1. สร้างไฟล์ `.github/prompts/write-tests.prompt.md`
2. ใส่ prompt ที่ดีที่สุดจาก Lab 1.3 ลงไป โดยให้รับชื่อ function จากคนเรียกใช้ และชี้ไปที่ test ตัวอย่างของ repo นี้ เช่น

   ```markdown
   ---
   agent: agent
   ---
   เขียน unit test ให้ function ที่ฉันระบุ
   ตั้งชื่อ test แบบเดียวกับ [stamps.test.js](../../tests/stamps.test.js)
   list edge case ก่อน รอฉัน OK แล้วค่อยเขียน ห้ามแก้ implementation
   ```

3. New Chat → Session Target **Local** (prompt file ไม่โหลดใน Copilot harness ซึ่งเป็นค่าเริ่มต้น)
4. พิมพ์ `/write-tests formatReceipt` แล้วดูว่าได้ผลแบบเดียวกับ Lab 1.3 หรือเปล่า

## เสร็จเมื่อ

`/write-tests` ขึ้นในรายการ `/` และรันได้

## ใช้โค้ดของตัวเอง

เก็บ prompt file ไว้ใน clone ของตัวเองก่อน อย่าเพิ่ง push จนกว่าทีมจะ review
