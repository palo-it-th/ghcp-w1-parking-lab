# Lab 1.5 · Context hygiene (5 นาที)

**เรื่องที่ฝึก:** context มีขีดจำกัด ส่งเข้าไปเฉพาะหลักฐานที่งานนั้นต้องใช้ และงานใหม่ให้เปิดแชตใหม่

## สถานการณ์

เมื่อวานมีลูกค้าร้องเรียนว่า "ใบเสร็จเกิน 1,000 บาทแล้วยังโดนเก็บเงิน"
log ของไม้กั้นทั้งวันอยู่ใน `logs/gate-2026-10-31.log` (ประมาณ 500 บรรทัด)

## ทำ

ทำสามรอบ แต่ละรอบเปิด **New Chat** ใหม่ ถามคำถามเดิม แล้วดูตัวเลขบน **context window control** ในช่องพิมพ์แชต
คำถาม: `ทำไมลูกค้าที่ร้องเรียนใน log นี้ถึงไม่ได้ชั่วโมงฟรี`

1. **Paste:** เปิดไฟล์ log, `Ctrl/Cmd+A`, copy แล้ว paste ทั้งหมดลงในแชต
2. **Attach ไฟล์:** แนบ `#gate-2026-10-31.log` ทั้งไฟล์
3. **Attach เฉพาะส่วน:** ค้นหา `customer_complaint` ในไฟล์ เลือกเฉพาะบรรทัดของ ticket ที่ร้องเรียนสัก 2–3 คน แล้วแนบเฉพาะส่วนที่เลือก

## เสร็จเมื่อ

จดตัวเลขบน context window control ทั้งสามรอบลงใน [`worksheet.md`](worksheet.md) และอธิบายได้ว่า:

- ทำไมการส่งน้อยลงถึงเสีย credit น้อยลง
- ทำไมงานใหม่ควรเปิด New Chat แทนที่จะคุยต่อในแชตเดิม ("one task, one chat")

## ใช้โค้ดของตัวเอง

ใช้ log หรือ stack trace ยาวๆ จากงานจริง (ระวังข้อมูลลูกค้าและ secret ใน log)
