# Lab 1.1 · ดู agent ทำงานหนึ่ง turn (7 นาที)

**เรื่องที่ฝึก:** ส่ง prompt ครั้งเดียว แต่ข้างใน agent วนหลายรอบ และทุกรอบ model อ่านทุกอย่างที่ผ่านมาใหม่หมด

## สถานการณ์

`tests.html` มี test สีแดงค้างอยู่หนึ่งตัว: `given_overnight_stay_when_calculated_then_each_day_capped_separately`
หัวหน้าถามว่ามันพังเพราะอะไร

## ทำ

1. เปิด setting `chat.agentHost.agentDebugLog.enabled` (setting ของ Copilot harness ซึ่งเป็นค่าเริ่มต้น)
   ต้องเปิด **ก่อน** ส่ง prompt เพราะมันไม่บันทึกย้อนหลัง
2. New Chat → role **Agent** → model **Auto**
3. ส่ง prompt นี้:

   ```text
   ทำไม test given_overnight_stay_when_calculated_then_each_day_capped_separately ใน tests/pricing.test.js ถึง fail
   อธิบายสาเหตุ ยังไม่ต้องแก้โค้ด
   ```

4. ถ้า Copilot ขอรันคำสั่งใน terminal ให้กด **Allow**
5. ตอบเสร็จแล้ว ให้กางรายการ tool call ใต้คำตอบออกดู
6. เปิด **...** → **Show Agent Debug Logs** เลือก session นี้ แล้ว filter ให้เหลือแต่ model request

## เสร็จเมื่อ

ตอบได้สามข้อ และจดลงใน [`worksheet.md`](worksheet.md):

- turn นี้มี model request กี่รอบ
- agent อ่านไฟล์อะไรบ้าง และรันคำสั่งอะไรบ้าง
- ทำไมรอบหลังๆ ถึงใช้ token มากกว่ารอบแรก

## ใช้โค้ดของตัวเอง

แก้โค้ดหนึ่งบรรทัดให้ test ที่มีอยู่ fail แล้วถาม Copilot แบบเดียวกัน
