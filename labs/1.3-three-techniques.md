# Lab 1.3 · สามเทคนิค (16 นาที)

**เรื่องที่ฝึก:** งานเดียวกัน ถามสามแบบ: zero-shot, few-shot และ chain-of-thought แล้วดูว่าแต่ละแบบได้ผลต่างกันยังไง

## สถานการณ์

`freeHoursFor()` ใน `src/stamps.js` คิดชั่วโมงจอดฟรีจากใบเสร็จ ตอนนี้มี test อยู่แค่สองตัวใน `tests/stamps.test.js`
กติกาอยู่ใน README หัวข้อ "กติกาค่าจอด" (ใบเสร็จร้านค้า, ตั๋วหนัง, ฟรีสูงสุด)

## ทำ

แต่ละรอบให้เปิด **New Chat** ใหม่ (role Agent) และกด **Undo** หลังจดผลแล้ว จะได้เริ่มจากโค้ดเดียวกันทุกรอบ

1. **Zero-shot:** ขอตรงๆ ไม่แนบตัวอย่าง

   ```text
   เขียน unit test ให้ freeHoursFor() ใน #stamps.js ห้ามแก้ implementation
   ```

2. **Few-shot:** แนบ test ที่มีอยู่สองตัวเป็นตัวอย่าง (`#stamps.test.js`) แล้วขอ test เพิ่ม "แบบเดียวกับตัวอย่าง"
3. **Chain-of-thought:** ให้ list edge case ก่อน โดยยังไม่เขียนโค้ด แล้วรอให้คุณเลือก

   ```text
   freeHoursFor() ใน #stamps.js คิดชั่วโมงจอดฟรีจากใบเสร็จ กติกาอยู่ใน #README.md
   list edge case ทั้งหมดก่อน ยังไม่ต้องเขียนโค้ด แล้วรอให้ฉัน OK
   ```

   เลือก case ที่ใช้ได้ แล้วค่อยบอกให้เขียน test
4. หลังแต่ละรอบ ให้รัน test (`node --test` หรือรีเฟรช `tests.html`) แล้วกรอก **ตารางเปรียบเทียบ** ใน [`worksheet.md`](worksheet.md)

## เสร็จเมื่อ

ตารางเปรียบเทียบมีครบสามแถว และคุณตอบได้ว่าเทคนิคไหนเจอ case ที่คุณเองคงนึกไม่ถึง

## ใช้โค้ดของตัวเอง

เลือก function ที่มี test อยู่แล้วอย่างน้อยสองตัว แล้วทำสามรอบแบบเดียวกัน
