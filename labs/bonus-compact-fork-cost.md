# โบนัส · /compact, /fork และราคาต่อ turn

สำหรับคนที่ทำ 6 lab เสร็จก่อนเวลา ทำข้อไหนก่อนก็ได้

## A · งานยาว: `/compact`

1. ในแชตเดียว ให้ Copilot แก้บั๊กค้างคืนจาก Lab 1.1 จนให้ test ทุกตัวเขียว แล้วให้ทำต่ออีกสักสองสามงานในแชตเดิม
2. ดู context window control ว่าใช้ไปกี่ %
3. พิมพ์ `/compact` แล้วดูตัวเลขอีกครั้ง

**ได้คำตอบเมื่อ:** บอกได้ว่าอะไรหายไปจาก context หลัง compact และอะไรยังอยู่

## B · ลองสองทาง: `/fork`

บั๊กจาก Lab 1.5 (ใบเสร็จที่มีเครื่องหมายจุลภาค เช่น `"1,250.00"`) แก้ได้อย่างน้อยสองที่: ตอนแปลงค่าใน `gate.js` หรือในตัวช่วยเรื่องเงินใน `money.js`

1. ให้ Copilot อธิบายสาเหตุก่อน
2. พิมพ์ `/fork` แล้วให้แชตแรกแก้ใน `gate.js` แชตที่ fork ออกมาแก้ใน `money.js`
3. เทียบ diff ของสองทาง

**ได้คำตอบเมื่อ:** บอกได้ว่าแชตที่ fork เริ่มด้วย context เต็มเท่าแชตเดิม (fork ไม่ได้ช่วยให้ context ว่างขึ้น) และเลือกได้ว่าจะเก็บทางไหน

## C · ราคาต่อ turn

1. hover ที่ model ใน model picker แล้วเปิดดู Pricing details
2. ส่ง prompt เดียวกันสามครั้ง ครั้งละ New Chat: Effort Level ต่ำ, Effort Level สูง และเปลี่ยน model
3. จดจำนวน token หรือ credit ที่ใช้ แล้วเทียบคุณภาพของคำตอบ

**ได้คำตอบเมื่อ:** บอกได้ว่าการตั้งค่าไหนคุ้มที่สุดสำหรับงานนี้ และเพราะอะไร
