# Lab 1.4 · Grill me (7 นาที)

**เรื่องที่ฝึก:** เมื่อยังไม่รู้ว่าต้องการอะไรแน่ ให้ Copilot ถามคุณแทน

## สถานการณ์

PM ส่ง ticket มา: [`docs/tickets/PARK-142-vip-parking.md`](../docs/tickets/PARK-142-vip-parking.md)
"สมาชิก VIP ควรได้สิทธิ์จอดพิเศษ" ไม่มีใครรู้ว่าพิเศษแปลว่าอะไร

## ทำ

1. New Chat → Local → Agent
2. ส่ง:

   ```text
   นี่คือ ticket #PARK-142-vip-parking.md สำหรับระบบใน #pricing.js และ #stamps.js
   grill me: ถามฉันทีละข้อจนกว่าจะเข้าใจว่าต้องทำอะไร ยังไม่ต้องเสนอวิธีแก้ และห้ามแก้โค้ด
   ```

3. ตอบคำถามตามที่คิดว่าสมเหตุสมผล ถ้าไม่รู้ ให้ตัดสินใจเองแล้วจดไว้ว่าต้องไปถาม PM
4. พอ Copilot หยุดถาม ให้มันสรุปออกมาเป็น acceptance criteria

## เสร็จเมื่อ

ใน [`worksheet.md`](worksheet.md) มีสองอย่าง:

- acceptance criteria ที่ test ได้ อย่างน้อย 3 ข้อ
- prompt หนึ่งอันที่มี Context + Goal + Constraint ครบ พร้อมส่งให้ agent ทำงานนี้ (ยังไม่ต้องส่ง)

## ใช้โค้ดของตัวเอง

ใช้ ticket จริงที่ยังเขียนไม่ชัดของทีมคุณแทน
