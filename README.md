# MegaLane Mall Parking · Workshop 1 Lab

Lab repo สำหรับ Workshop 1 · Prompt + Context Engineering ของ GitHub Copilot Adoption Program

## เรื่องของ repo นี้

คุณเพิ่งย้ายเข้าทีมที่ดูแล **ระบบคิดค่าจอดรถของห้าง MegaLane** (ห้างสมมติ)
คนเขียนโค้ดเดิมย้ายทีมไปแล้ว รายงานเมื่อเช้ามีตัวเลขแปลกๆ มีลูกค้าร้องเรียนเมื่อวาน และ PM ส่ง ticket ใหม่มารออยู่
งานของคุณวันนี้คือใช้ Copilot เคลียร์งานพวกนี้ **โดยถามให้แม่น และไม่ใส่ของเกินจำเป็นลงใน context**

### กติกาค่าจอด (ทุกคนรู้จักอยู่แล้ว)

| กติกา | รายละเอียด |
|---|---|
| ฟรี 15 นาทีแรก | จอดไม่เกิน 15 นาที ไม่เสียเงิน |
| ชั่วโมงละ 20 บาท | เกิน 15 นาทีแล้ว นับจากเวลาเข้า เศษของชั่วโมงปัดขึ้นเป็นหนึ่งชั่วโมง |
| เพดานวันละ 300 บาท | คิดแยกตามวันในปฏิทิน ชั่วโมงไหนเริ่มในวันไหน นับเป็นของวันนั้น |
| บัตรหาย | เหมาจ่าย 500 บาท |
| ใบเสร็จร้านค้า (stamp) | ซื้อในวันเดียวกับวันที่ออก รวมยอดได้ ครบ 1,000 บาทจอดฟรี 2 ชั่วโมง ครบ 3,000 บาทจอดฟรี 4 ชั่วโมง |
| ตั๋วหนัง | จอดฟรีเพิ่ม 3 ชั่วโมง ใช้ร่วมกับใบเสร็จร้านค้าได้ |
| ฟรีสูงสุด | ไม่เกิน 6 ชั่วโมงต่อครั้ง ชั่วโมงฟรีหักจากชั่วโมงแรกๆ ของการจอด |

ในโค้ด เงินเป็น **สตางค์จำนวนเต็ม** เสมอ (`2000` = 20 บาท) และเวลาเป็น ISO 8601 เวลากรุงเทพฯ (`+07:00`)

## เริ่มต้น (2 นาที)

ไม่ต้องติดตั้งอะไร

1. Clone repo นี้ แล้วเปิดโฟลเดอร์ใน VS Code
2. ดับเบิลคลิก `index.html` เพื่อดูหน้าจอจ่ายค่าจอด และ `tests.html` เพื่อดู test (ตอนเริ่มต้องเขียวทุกตัว)
3. ถ้าเครื่องมี Node (เวอร์ชัน 20 ขึ้นไป) ให้รัน test ใน terminal ได้ด้วย:

   ```bash
   node --test
   ```

   ไม่มี Node ก็ทำทุก lab ได้ แค่ Copilot จะรัน test เองไม่ได้
4. ตั้งค่า Copilot Chat: เปิด **New Chat** (ใช้ Copilot harness ที่เป็นค่าเริ่มต้น) → role **Agent** → model **Auto**
5. เปิดไฟล์ [`labs/worksheet.md`](labs/worksheet.md) ไว้ข้างๆ ทุกครั้งที่รู้ตัวว่าพิมพ์ประโยคเดิมซ้ำ ให้จดลงในนั้น
